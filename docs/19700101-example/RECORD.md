# 示例档案（模板占位）

> 档案：历史任务记录，非现状。现状以代码与 FACTS.md 为准。
> 原样迁出自 `<模块>/FACTS.md`（git <哈希> 第 N–M 行；锚 '<commit subject>' @<YYYY-MM-DD>），正文未改动。

## 写法示范

**根因**：一句话说清机制层面的真相（不是"某处坏了"，是"什么机制导致必然坏"）。
**判别证据链**：可复现的观察、日志路径、排除掉的候选因（被否的假设同样有价值）。
**修复**：改了什么、为什么这样改。
**验证**：怎么确认修好了（命令、指标、时长）。
**遗留**：证据强度不足的结论标"疑似/无法回溯确认"，不许把假设写成定案。

档案只增不改。结案即冻结，Frozen 是它的特性不是缺陷。
